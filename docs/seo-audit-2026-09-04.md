## 2. Corrections effectuées dans cette phase

- **Canonical ajouté sur 17 pages** (0 → 17). C'était le trou technique le plus important : sans canonical, toute future variante locale (Lyon 6, Oullins, etc.) aurait un vrai risque de contenu dupliqué aux yeux de Google.
- **`LocalBusiness` ajouté** en complément de `AutoDetailing` (déjà présent) sur les 17 pages qui portaient ce bloc — passage de `"@type": "AutoDetailing"` à `"@type": ["AutoDetailing", "LocalBusiness"]`. Un seul établissement, une seule adresse (47 chemin du Pras, La Mulatière) : aucune fausse implantation créée.
- **`BreadcrumbList` ajouté** sur les 9 pages qui ont déjà un fil d'Ariane visible (PPF, Céramique, Polissage, Nettoyage, Vitres teintées, Wrap, Rénovation jantes, Detailing premium, Realisation) — la donnée structurée reflète exactement ce qui est visible à l'écran, rien d'ajouté qui ne soit pas déjà affiché.
- **`sitemap.xml`** : ajout d'un `lastmod` réel sur les 16 URL existantes. Aucune URL ajoutée ou retirée dans cette phase.
- **Bug HTML corrigé** sur `vitres-teintees.html` : la balise `<meta name="description">` n'était pas fermée (`>` manquant), ce qui cassait potentiellement le parsing de la balise `<link rel="preconnect">` suivante. Corrigé.
- **34 blocs JSON-LD vérifiés valides** (parsing JSON strict) après toutes les modifications.
